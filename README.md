## 📌 About the Project

This project is developed as part of the **Software Engineering and Quality Assurance (SEQA)** subject.

The application demonstrates important software engineering concepts such as:

- 🏗️ Software development
- 🧪 Software testing
- ✅ Quality assurance
- 🔄 Version control using Git and GitHub
- 🌐 Web application development
- 📊 Data management using JSON
- 🚀 Application deployment

The project uses a **Node.js and Express.js backend** with an interactive web interface developed using **HTML and CSS**.

---

## 🎯 Objectives

The main objectives of this project are:

- 💻 Develop a functional web-based application.
- 🏗️ Apply software engineering principles.
- 🧪 Perform testing and identify possible errors.
- 🔍 Improve software quality and reliability.
- 🔄 Use Git and GitHub for version control.
- 📁 Manage application data using a JSON database.
- 🚀 Deploy the application for online access.
